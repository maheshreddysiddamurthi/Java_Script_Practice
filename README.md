🧭 JavaScript Roadmap (Modern – 2025 Edition)
---------------------------------------------

1. CORE MODERN SYNTAX (ES6+)
----------------------------
✅ Must-Learn Topics:
- let, const (stop using var)
- Template literals: `Hello, ${name}`
- Arrow functions: const add = (a, b) => a + b
- Destructuring: const { name } = user;
- Spread / Rest: ..., [...arr], {...obj}
- Default Parameters: function fn(x = 10)
- Ternary operator: condition ? a : b
- Short-circuiting: value && doSomething()
- Optional chaining: user?.address?.city
- Nullish coalescing: input ?? "default"
- Logical assignment: a ||= b, a &&= b
- Named & default exports (ES modules)
- Strict equality (=== and !==)

2. MODERN DATA HANDLING
------------------------
✅ Arrays & Objects:
- .map(), .filter(), .reduce()
- .find(), .some(), .every(), .includes()
- Object.entries(), Object.values(), Object.keys()
- Set, Map – for unique collections and key-value pairs

3. ASYNC PROGRAMMING (2025)
----------------------------
✅ Essentials:
- async / await
- Fetch API: await fetch()
- AbortController (cancel fetch)
- Promise combinators:
    - Promise.all(), Promise.allSettled(), Promise.any()
- for await...of (for async iterables)

4. MODULES & BUNDLING
----------------------
✅ You should learn:
- ES Modules (ESM): import, export
- Tree shaking (only import what you use)
- import.meta, dynamic imports
- Build tools: Vite, ESBuild, or Webpack 5

5. DOM MANIPULATION (MODERN)
-----------------------------
✅ Modern Features:
- document.querySelector()
- addEventListener
- Live DOM updates: innerHTML, textContent
- Element class/style updates: classList.add()
- Event delegation
- IntersectionObserver for lazy-loading
- MutationObserver for detecting DOM changes

6. STORAGE & WEB APIs
----------------------
✅ Most-used in 2025:
- Local Storage & Session Storage
- Fetch + REST APIs
- FormData, Blob, FileReader
- Intl for formatting currencies, dates, etc.
- Clipboard API (copy/paste)
- Notification API
- WebSocket (live data)

7. TOOLING ECOSYSTEM
---------------------
✅ Tools in 2025:
- ESLint + Prettier (Lint + Format)
- Vite (Modern build tool)
- NPM / Yarn / pnpm (Package managers)
- Vitest / Jest (Unit testing)
- Playwright / Cypress (E2E testing)
- Babel (for legacy browser support)

8. ADVANCED CONCEPTS
---------------------
✅ 2025-Relevant:
- Closures
- Event loop & microtasks/macrotasks
- Prototypes & class inheritance
- this in arrow vs regular functions
- Functional programming (immutability, purity)
- Throttle & debounce (requestAnimationFrame)
- Symbols and Iterators
- Generators: function*

9. BUILD WITH MODERN JS
-------------------------
✅ Real-world Projects:
- SPA with Vanilla JS + Vite
- Weather App using Fetch + OpenWeather API
- Custom Modal/Dialog Component
- Drag-and-drop Kanban board
- Realtime Chat (WebSocket or Firebase)

OPTIONAL (ADVANCED USE CASES)
------------------------------
- Web Workers – background threading
- Service Workers – PWA features
- IndexedDB – client-side database
- Streams API – handle large data
- Temporal API – future Date API replacement
